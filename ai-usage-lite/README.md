# AI Usage Lite

Noctalia v5 的 Codex / OpenCode Go 订阅用量插件，由现有 ai-usagebar CLI 查询数据。

- 状态栏：Codex 图标、紧凑双行剩余额度和重置倒计时。
- 展开页：双订阅额度、Codex 手动重置次数、剩余有效时间及到期时刻。
- 手动刷新、单一查询服务、超时、防并发和上次成功数据缓存。

插件 ID：`pupu/ai-usage-lite`；状态栏组件：`pupu/ai-usage-lite:bar`。

[快速安装、使用与开发说明](https://github.com/Lemonadepu21/noctalia-ai-usage-lite#readme)
