# Provider logos

Bundled SVGs from [Lobe Icons](https://github.com/lobehub/lobe-icons), MIT licensed (see LICENSE).
Upstream revision: `8a1b2821bb768c484fe8da20c5e1838b6bf551a9`.
Source paths: `packages/static-svg/icons/<name>.svg`.
The only modification replaces `currentColor` with `#eeeeee` for dark themes and `#222222` for light themes.
Brand names and trademarks remain the property of their respective owners.

OpenAI and GitHub Copilot use Noctalia's built-in Tabler glyphs. Named accounts reuse their backend `brand` logo. Unknown brands, including OrcaRouter, Lyceum and Muse Code, retain a generic icon until a suitable logo is added. Backend values are never used as file paths or image URLs.

Assets load locally through Noctalia's image cache. No icon downloads, additional processes, or periodic popup renders are needed.
